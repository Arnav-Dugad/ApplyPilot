# Application rules

Rules return one of `ALLOW`, `ASK`, or `BLOCK`, with an explanation.

Default blocks include definite qualification mismatch, definite graduation exclusion, permanent-role mismatch while internship-only mode is active, known lack of required work authorization, duplicate application, unknown required field at submission, unapproved generated text, expired data, missing/unapproved CV, or failed declaration validation.

Default asks include ambiguous sponsorship wording, required relocation, mandatory salary, unusual legal declarations, and any unknown answer. Preferences influence ranking only; they do not create eligibility facts.
